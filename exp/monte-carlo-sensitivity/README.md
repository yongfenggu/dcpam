# 蒙特卡罗灵敏度分析

端到端测量方法的三类影响因素灵敏度分析。数据来源：`dataset/samples/spot-measurements.csv`（172 样本，5 组）。

## 分析范围

按用户要求，聚焦三类影响因素，**从像素到设备坐标系这一步假设无误差**（直接用 CSV 里已有的设备系实像点坐标作为无误差输入），只对下列三类因素做扰动，重跑 **镜像 → 距离** 计算：

1. **光斑提取**：像素中心 (u,v) 偏移几个像素对最终距离的影响
2. **反射镜安装**：前/后反射镜的位置 (x,y,z) 和角度（绕 x/y）扰动
3. **探测杆（靶点）**：根部 root 的 XYZ 误差 + 杆长 length 误差，并扫描杆长 100~1200 mm 看灵敏度随长度的变化

## 运行

```bash
uv run python exp/monte-carlo-sensitivity/mc_sensitivity.py
```

输出到 `results/`：
- `mc_spot.json` — 光斑像素偏移灵敏度
- `mc_mirror.json` — 反射镜安装灵敏度
- `mc_probe_rod.json` — 探测杆灵敏度（含杆长扫描）
- `summary.md` — 汇总表

## 核心结论

### 1. 光斑提取：每偏 1 像素的影响

| 方向 | ±1px | ±2px |
|------|------|------|
| 前相机 u（水平） | **10.6 μm** | 21.2 μm |
| 前相机 v（垂直） | 0.1 μm | 0.2 μm |
| 后相机 u（水平） | **3.3 μm** | 6.7 μm |
| 后相机 v（垂直） | 0.0 μm | 0.0 μm |

**关键发现**：
- **u 方向（水平）远比 v 方向（垂直）敏感**，前相机 1px ≈ 10.6 μm，后相机 1px ≈ 3.3 μm。
- v 方向几乎无影响（< 0.1 μm/px），原因是反射镜法向在 xz 平面内（normal=[√2/2, 0, √2/2]），v 方向像素偏移经反投影后主要落在 y 轴，而镜像反射和激光轴线构造对 y 方向偏移不敏感。
- 前相机比后相机敏感约 3 倍，符合光路放大比差异。

### 2. 反射镜安装

| 自由度 | 1 mm / 1° 扰动 |
|--------|---------------|
| 前镜 x 平移 | **874.9 μm** |
| 前镜 z 平移 | **874.9 μm** |
| 前镜 y 平移 | 0.0 μm |
| 前镜绕 y 转 | **641.3 μm** |
| 前镜绕 x 转 | 48.1 μm |
| 后镜 x 平移 | 302.7 μm |
| 后镜 z 平移 | 302.7 μm |
| 后镜 y 平移 | 0.0 μm |
| 后镜绕 y 转 | 203.4 μm |
| 后镜绕 x 转 | 16.2 μm |

**关键发现**：
- **前反射镜是最大瓶颈**：x/z 平移 1 mm 导致 ~875 μm 误差，绕 y 转 1° 导致 ~641 μm。
- y 方向（垂直）平移无影响，与光斑 v 方向不敏感一致——整个光学链路在 yz 平面内对 y 不敏感。
- 前镜比后镜敏感约 2.8 倍（875 vs 303），因为前镜到靶点的光路更短、放大比更大。

### 3. 探测杆（靶点）

| 方向 | 1 mm 误差 |
|------|----------|
| root_x（水平） | 24.5 μm/mm |
| root_y（垂直） | 4.4 μm/mm |
| root_z（杆长方向） | **999.5 μm/mm** |
| length（杆长） | **999.5 μm/mm** |

**随杆长变化**（每 mm 误差对应的 μm）：

| 杆长 | root_x | root_y | root_z / length |
|------|--------|--------|-----------------|
| 100 mm | 24.4 | 11.6 | 999.4 |
| 600 mm | 24.5 | 4.3 | 999.5 |
| 1200 mm | 24.5 | 2.7 | 999.5 |

**关键发现**：
- **杆长 / root_z 是绝对主导因素**：1 mm 误差 ≈ 1000 μm（1:1 传递），因为靶点 = root + [0,0,-length]，z 方向和 length 直接决定靶点位置，而距离公式对靶点垂直于激光轴的偏移 1:1 响应。
- **root_z 和 length 完全等价**：二者都沿同一方向影响靶点，无法区分。
- **root_x 随杆长几乎不变**（~24.5 μm/mm），因为 x 方向偏移投影到垂直激光轴方向的分量稳定。
- **root_y 随杆长增大而衰减**（11.6 → 2.7 μm/mm），杆越长，y 方向偏移的相对影响越小。
- 这与 `exp/和跟踪仪对比精度/基准线拟合记录.md` 中发现的 **-23.913 mm 系统偏差**高度吻合——该偏差很可能来自杆长/球心 z 方向偏置。

## 方法说明

- **光斑像素灵敏度**：从 CSV 数据数值估计像素→设备系实像点的雅可比矩阵 J (6×4)，对像素坐标加 Δpx 扰动后用 J 映射到设备系实像点偏移，再跑镜像+距离。这避免了重新做反投影（用户要求假设该步无误差）。
- **反射镜 / 探测杆**：直接用 CSV 设备系实像点作为无误差输入，只扰动镜面参数或靶点坐标。
- 基线复算残差为 0.00 μm，确认计算链路正确。
