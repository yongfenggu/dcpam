## 1. 分析框架

### 1.1 测量原理

DCPAM 通过以下步骤测量靶点 T 到激光轴的距离 H：

1. 双相机成像激光光斑
2. 反投影至实像面
3. 转入设备坐标系（此步假设无误差）
4. 关于前/后反射镜做镜像，得到虚像点 P₁、P₂
5. 构造激光轴 L = P₂ − P₁
6. 计算 H = |L × w| / |L|，其中 w = T − P₁

### 1.2 两种测量模式

- **单次测量**：单个靶点位置，关心 H 本身
- **差值测量**：同一激光轴下两个靶点位置 T_A、T_B，关心 ΔH = H_A − H_B

### 1.3 误差分类

| 误差类型 | 作用对象 | 物理机制 | 差值行为 |
|---------|---------|---------|---------|
| 靶点误差（T_x, T_y, T_z/杆长） | 被测物位置 | 平移靶点，不改激光轴 | **抵消** |
| 镜面误差（位置/角度） | 激光轴方位 | 改变 P₁/P₂ → 激光轴偏转 | **放大** |

## 2. 完整自由度

每镜 6 个自由度中，y 平移不敏感（验证 0.00 μm/mm），有效 5 个；加靶点 3 个，共 **13 个**。

| 部件 | 自由度 | 数量 |
|------|--------|------|
| 前镜 | x平移, z平移, 绕x, 绕y, 绕z | 5 |
| 后镜 | x平移, z平移, 绕x, 绕y, 绕z | 5 |
| 靶点 | x, y, z(=杆长) | 3 |

## 3. 统一灵敏度值

对每个自由度，H 是参数的非线性函数：

$$H(\delta) = H_0 + a\cdot\delta + b\cdot\delta^2 + \cdots$$

- **统一灵敏度** = |a|（一阶导数绝对值，正负方向通用）
- **非对称度** = |bδ/a|（<100% 时线性近似可靠）
- 计算方法：中心差分 a = [H(+δ) − H(−δ)] / (2δ)

### 4.2 三个梯队

- **第一梯队**（>400 μm/单位）：杆长 + 镜面 x/z 平移 → 单次测量主导
- **第二梯队**（30–435 μm/单位）：镜面绕y旋转 + 绕x/z旋转
- **第三梯队**（<6 μm/单位）：靶点 y → 可忽略

### 4.3 差值测量中的关键现象

**靶点误差完全抵消，镜面误差放大。**

放大机制：镜面偏移 → 激光轴偏转角 θ → 差值误差 ≈ 间距 D × θ

$$\Delta(\Delta H)_{\text{镜面}} \approx D \times \theta \quad\quad \Delta(\Delta H)_{\text{靶点}} = 0$$

放大倍数 ≈ D / |L|（|L| ≈ 80mm）。间距 300mm 时放大约 8 倍，1200mm 时约 15 倍。

## 7. 与实验数据的关联

实验发现 -23.913mm 系统偏差在 262–1192mm 全量程内**恒定，与距离无关**。本分析解释：
- 镜面误差 → 偏差随间距放大 → 与"恒定"特征不吻合
- 杆长/球心偏移 → 单次测量恒定偏差，差值测量中抵消 → 与特征吻合

结论：-23.913mm 偏差更可能来自杆长/球心 z 方向偏置，而非镜面安装误差。
